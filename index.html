ElectricBits Agent

A private tool by Electric (ElectricBits)

ElectricBits Agent is the small helper behind Electric's personal assistant, Nima. It reads the statistics of Electric's own creator accounts (views, likes, followers) so he can see them in one place. It never posts, comments or changes anything, and it only works with accounts he owns.
